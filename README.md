**AMBA AHB to APB Bridge**

**Project Overview**

This project focuses on the design and implementation of an AMBA AHB-to-APB Bridge using Verilog HDL.

The bridge enables communication between the high-performance AHB interface and the low-power APB interface.

**Objectives**

- Design an AHB-to-APB bridge using Verilog HDL.
- Understand communication between AHB and APB protocols.
- Implement the RTL design.
- Verify the design using a Verilog testbench.

**Project Structure**

**Tools and Technologies**

- HDL: Verilog
- Design Tool: Xilinx Vivado
- Simulation Tool: Vivado Simulator
- Design: RTL Design
- Verification: Verilog Testbench

**Design and Verification**

The bridge RTL design is implemented in Verilog HDL. A separate testbench is provided to simulate and verify the design.
